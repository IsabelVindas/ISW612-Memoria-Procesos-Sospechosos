¿Qué hace esta herramienta?

Esta aplicación permite analizar el consumo de memoria de los procesos de Windows, identificar posibles comportamientos anormales y consultar el estado de algunas protecciones de seguridad.

¿Cómo utilizarla?

  1. 1. Cargar datos: selecciona un archivo JSON generado por PowerShell o utiliza los datos de ejemplo.
  2. 2. Analizar resultados: revisa el resumen, los gráficos, los procesos y las alertas detectadas.
  3. 3. Exportar: descarga el JSON o guarda el reporte como PDF.

Los datos se procesan localmente en tu navegador. No se envían a servidores externos.

¿Qué hace esta aplicación?

Esta aplicación permite analizar registros de memoria y procesos de Windows recopilados mediante PowerShell. Su objetivo es identificar comportamientos que requieren revisión, como aumentos sostenidos de memoria.

¿Cómo funciona?

Primero se ejecuta el monitor de PowerShell en un entorno de pruebas autorizado. El monitor genera un archivo JSON con las mediciones.

Después, la aplicación web permite cargar ese archivo, consultar gráficos, revisar alertas, buscar procesos y exportar los resultados.

Herramientas utilizadas

Se utilizan PowerShell, HTML, CSS y JavaScript. El análisis web se realiza localmente en el navegador, sin necesidad de un servidor.

Interpretación de resultados

Las alertas indican comportamientos que requieren revisión. El umbral configurable de la aplicación permite identificar procesos cuya memoria privada aumentó entre la primera y la última medición.

Esta comparación es adicional a las alertas originales generadas por PowerShell y no equivale necesariamente a detectar un crecimiento sostenido.

Limitaciones

Un aumento de memoria no demuestra por sí solo la presencia de malware. Las alertas deben interpretarse considerando el comportamiento normal del equipo.

El estado de LSA Protection y Credential Guard corresponde al momento en que se recopilaron los datos y no representa una evaluación completa de seguridad.
